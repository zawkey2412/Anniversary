How do I get a token? (one-time, 2 minutes)
  1. Open github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → pick this repo.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate, copy it, and paste it below. It stays in this browser only and is never put in the website.
